# Planning
1. Before touching code, write `PLAN.md` in the working dir with a checklist of 3-8 concrete steps:
   `- [ ] step`
2. Execute steps strictly in order.
3. After finishing each step, mark it with edit_file: replace `- [ ] step` with `- [x] step`.
4. If the plan turns out wrong, update PLAN.md first, then continue.
5. At the end read PLAN.md: all items must be `[x]`. Then give the final summary.
